# PyInstaller 패키징 가이드 — macOS / Windows

## 핵심 원칙

> **PyInstaller는 크로스 컴파일을 지원하지 않는다.**
> macOS 실행 파일은 macOS에서, Windows 실행 파일은 Windows에서 각각 빌드해야 한다.

---

## 사전 준비 (공통)

| 항목 | 버전 | 확인 명령 |
|------|------|-----------|
| Python | 3.10 이상 | `python3 --version` (Mac) / `python --version` (Win) |
| pip | 최신 권장 | `pip --version` |
| Git | 임의 | `git --version` |

> Ollama, Qwen3 모델은 실행 시 별도로 필요. 빌드 자체에는 불필요.

---

## macOS 빌드

### 1단계 — 저장소 복제 및 이동

```bash
git clone https://github.com/jamiewell/daily_check_agent.git
cd daily_check_agent/daily-check-agent
```

### 2단계 — 빌드 스크립트 실행

```bash
chmod +x build.sh
./build.sh
```

스크립트가 자동으로 수행하는 작업:

| 단계 | 내용 |
|------|------|
| 가상환경 생성 | `.venv/` (없을 때만) |
| 패키지 설치 | `requirements.txt` + `pyinstaller` |
| PyInstaller 빌드 | `daily_check_agent.spec` 기준 |
| 운영 파일 복사 | `config.yaml`, `templates/`, `sample_data/` → `dist/` |
| ZIP 생성 | `dist/daily-check-agent.zip` |

### 3단계 — 결과물 확인

```
dist/
└── daily-check-agent/
    ├── daily-check-agent     ← macOS 실행 파일
    ├── _internal/            ← Python 런타임 (수정 금지)
    ├── config.yaml
    ├── templates/
    ├── sample_data/
    └── reports/
```

### 4단계 — 동작 확인

```bash
cd dist/daily-check-agent
./daily-check-agent --help
./daily-check-agent check --no-save
```

## Windows 빌드

### 1단계 — 저장소 복제 및 이동



```
    ├── sample_data\
```

```bat
cd dist\daily-check-agent
daily-check-agent.exe --help
daily-check-agent.exe check --no-save
```

## 수동 빌드 (스크립트 없이 단계별 실행)

### macOS

```bash
# 가상환경
python3 -m venv .venv
source .venv/bin/activate

# 패키지 설치
pip install -r requirements.txt
pip install pyinstaller

# 빌드
pyinstaller daily_check_agent.spec --clean --noconfirm

# 운영 파일 복사
cp config.yaml             dist/daily-check-agent/
cp -r templates/           dist/daily-check-agent/templates/
cp -r sample_data/today/   dist/daily-check-agent/sample_data/today/
cp -r sample_data/yesterday/ dist/daily-check-agent/sample_data/yesterday/
mkdir -p dist/daily-check-agent/reports
```

### Windows (PowerShell)

```powershell
# 가상환경
python -m venv .venv
.venv\Scripts\Activate.ps1

# 패키지 설치
pip install -r requirements.txt
pip install pyinstaller

# 빌드
pyinstaller daily_check_agent.spec --clean --noconfirm

# 운영 파일 복사
Copy-Item config.yaml              dist\daily-check-agent\
Copy-Item templates -Recurse       dist\daily-check-agent\templates
Copy-Item sample_data\today -Recurse     dist\daily-check-agent\sample_data\today
Copy-Item sample_data\yesterday -Recurse dist\daily-check-agent\sample_data\yesterday
New-Item -ItemType Directory -Force dist\daily-check-agent\reports
```

## 폐쇄망 전달 패키지 구성

빌드 후 생성되는 `dist/daily-check-agent.zip` 외에 Ollama와 모델 파일을 함께 전달한다.

```
전달 파일 목록
├── daily-check-agent.zip      ← PyInstaller 빌드 산출물
├── ollama                     ← Ollama 바이너리 (macOS) 또는 OllamaSetup.exe (Windows)
└── qwen3-8b-q4_k_m.gguf      ← Qwen3 모델 파일 (사전 다운로드)
```

### Ollama 바이너리 사전 확보 방법

**macOS**
```bash
# Homebrew로 설치 후 바이너리 위치 확인
which ollama       # → /usr/local/bin/ollama 또는 /opt/homebrew/bin/ollama
cp $(which ollama) ./ollama
```

**Windows**
- [https://ollama.com/download](https://ollama.com/download) 에서 `OllamaSetup.exe` 다운로드

### Qwen3 모델 사전 다운로드 방법

```bash
# 인터넷 환경에서 pull
ollama pull qwen3

# 모델 파일 위치 확인 후 복사
# macOS: ~/.ollama/models/
# Windows: C:\Users\<사용자>\.ollama\models\
```

### 폐쇄망 서버에서 Ollama 모델 등록

```bash
# 모델 파일을 Ollama 모델 경로에 복사
export OLLAMA_MODELS=/opt/ollama-models   # 원하는 경로 지정
./ollama serve &                          # 백그라운드 실행
./ollama run qwen3 "테스트"               # 동작 확인
```

## 주의사항

| 항목 | 내용 |
|------|------|
| 플랫폼 분리 | macOS 빌드와 Windows 빌드는 별도로 진행 |
| `_internal/` | 런타임 폴더, 수정하거나 이동하면 실행 불가 |
| `config.yaml` | Grafana URL / 토큰 / 임계값은 배포 전 반드시 편집 |
| 실행 위치 | 반드시 `dist/daily-check-agent/` 폴더 내에서 실행 |
| AV 오탐 | PyInstaller 바이너리는 일부 백신에서 오탐 발생 가능, UPX 압축 비활성화로 완화 |
| Python 버전 | 빌드 PC와 실행 PC의 OS 버전이 크게 다르면 오류 발생 가능 |

## 트러블슈팅

### `ModuleNotFoundError: No module named 'yaml'`
```bash
# spec 파일의 hiddenimports 에 추가됐는지 확인
grep yaml daily_check_agent.spec
```

### `FileNotFoundError: config.yaml`
```bash
# 실행 위치 확인 — config.yaml 이 있는 폴더에서 실행해야 한다
ls config.yaml   # 이 파일이 보여야 한다
```

### Windows: `Activate.ps1 실행 정책 오류`
```powershell
Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser
```

### macOS: `permission denied`
```bash
chmod +x dist/daily-check-agent/daily-check-agent
chmod +x build.sh
```
