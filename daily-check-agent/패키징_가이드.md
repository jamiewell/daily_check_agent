# PyInstaller 패키징 가이드 — macOS / Windows

## 핵심 원칙

> **PyInstaller는 크로스 컴파일을 지원하지 않는다.**
> 각 OS에서 실행할 파일은 반드시 해당 OS에서 빌드해야 한다.

| 빌드 OS | 생성 파일 형식 | 확장자 |
|---------|--------------|--------|
| macOS | Unix 실행 파일 (Mach-O) | 없음 (`daily-check-agent`) |
| Windows | Windows 실행 파일 (PE) | `.exe` (`daily-check-agent.exe`) |

> **macOS 에서 빌드한 파일은 Windows 에서 실행 불가. Windows .exe 가 필요하면 Windows PC 에서 직접 빌드해야 한다.**

---

## LLM 백엔드 선택

이 에이전트는 두 가지 LLM 백엔드를 지원한다.

| 항목 | Ollama 모드 | llama.cpp 모드 |
|------|------------|---------------|
| 설치 | Ollama 별도 설치 필요 | 설치 없음 (exe에 포함) |
| 모델 크기 | Qwen3 (수 GB) | Qwen3-0.6B Q4 (~500MB) |
| 저사양 PC | RAM 16GB 이상 권장 | RAM 8GB 이상 가능 |
| 설정 | `config.yaml` ollama 섹션 | `config.yaml` llama_cpp.enabled: true |
| exe 더블클릭 | 별도 Ollama 실행 필요 | llama-server 자동 기동 |

**폐쇄망 데모** 또는 **저사양 Windows PC** 는 llama.cpp 모드를 권장한다.

## macOS 빌드

### 사전 준비

| 항목 | 확인 명령 |
|------|-----------|
| Python 3.10 이상 | `python3 --version` |
| Git | `git --version` |

### 빌드 순서

```bash
# 1. 저장소 복제
git clone https://github.com/jamiewell/daily_check_agent.git
cd daily_check_agent/daily-check-agent

# 2. 빌드 (가상환경·패키지 설치·PyInstaller 모두 자동)
chmod +x build.sh
./build.sh
```

### 결과물

```
dist/daily-check-agent/
├── daily-check-agent     ← macOS 전용 실행 파일 (.exe 아님)
├── _internal/            ← Python 런타임 (수정 금지)
├── config.yaml
├── templates/
├── sample_data/
└── reports/
```

### 동작 확인

```bash
cd dist/daily-check-agent
./daily-check-agent check --no-save
```

## Windows 빌드

### 1단계 — Python 설치

1. [https://www.python.org/downloads/](https://www.python.org/downloads/) 에서 Python 3.10~3.12 다운로드
2. 설치 시 **"Add Python to PATH"** 반드시 체크
3. 설치 후 확인:

```powershell
python --version
pip --version
```

### 2단계 — Git 설치 (없는 경우)

[https://git-scm.com/download/win](https://git-scm.com/download/win) 에서 다운로드 후 설치.

### 3단계 — 저장소 복제

```bat
git clone https://github.com/jamiewell/daily_check_agent.git
cd daily_check_agent\daily-check-agent
```

### 4단계 — (llama.cpp 모드) runtime 폴더 준비

llama.cpp 모드로 빌드할 경우에만 해당. Ollama 모드는 이 단계 건너뜀.

#### llama-server.exe 다운로드

1. [https://github.com/ggml-org/llama.cpp/releases/latest](https://github.com/ggml-org/llama.cpp/releases/latest) 접속
2. Assets 에서 **`llama-<버전>-bin-win-avx2-x64.zip`** 다운로드
   - AVX2 미지원 구형 CPU: `llama-<버전>-bin-win-noavx-x64.zip`
3. 압축 해제 후 `llama-server.exe` 를 아래 경로에 복사:

```
daily-check-agent\
└── runtime\
    └── llama-server.exe   ← 여기에 복사
```

#### GGUF 모델 다운로드

1. [https://huggingface.co/Qwen/Qwen3-0.6B-GGUF](https://huggingface.co/Qwen/Qwen3-0.6B-GGUF) 접속
2. `qwen3-0.6b-q4_k_m.gguf` 파일 다운로드 (~500MB)
3. 아래 경로에 저장:

```
daily-check-agent\
└── runtime\
    └── models\
        └── qwen3-0.6b-q4_k_m.gguf   ← 여기에 저장
```

완성된 runtime 폴더 구조:

```
runtime\
├── llama-server.exe
└── models\
    └── qwen3-0.6b-q4_k_m.gguf
```

#### config.yaml 에서 llama.cpp 모드 활성화

```yaml
llama_cpp:
  enabled: true          # ← false → true 로 변경
  port: 8080
  model_file: "runtime/models/qwen3-0.6b-q4_k_m.gguf"
  context_size: 2048     # 저사양 PC: 1024
  threads: 4             # 저사양 PC: 2
  max_tokens: 512        # 저사양 PC: 256
```

### 5단계 — 빌드 스크립트 실행

**명령 프롬프트(cmd)** 또는 **PowerShell** 에서 실행:

```bat
build.bat
```

스크립트가 자동으로 수행하는 작업:

| 단계 | 내용 |
|------|------|
| 가상환경 생성 | `.venv\` (없을 때만) |
| 패키지 설치 | `requirements.txt` + `pyinstaller` |
| PyInstaller 빌드 | `daily_check_agent.spec` 기준 |
| 운영 파일 복사 | `config.yaml`, `templates\`, `sample_data\`, `runtime\` → `dist\` |
| ZIP 생성 | `dist\daily-check-agent.zip` |

> PowerShell 실행 정책 오류 발생 시:
> ```powershell
> Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser
> ```

### 6단계 — 결과물 확인

```
dist\daily-check-agent\
├── daily-check-agent.exe   ← Windows 전용 실행 파일
├── _internal\              ← Python 런타임 (수정 금지)
├── config.yaml
├── templates\
├── sample_data\
├── runtime\                ← llama.cpp 모드 시에만 존재
│   ├── llama-server.exe
│   └── models\
│       └── qwen3-0.6b-q4_k_m.gguf
└── reports\
```

### 7단계 — 동작 확인

```bat
cd dist\daily-check-agent

REM Ollama 모드: 연결 상태 먼저 확인
daily-check-agent.exe status

REM 메트릭 점검 (LLM 없음, 빠름)
daily-check-agent.exe check --no-save

REM AI 분석 (llama.cpp 모드: llama-server 자동 기동)
daily-check-agent.exe analyze
```

### exe 더블클릭 동작

exe 를 더블클릭하면 인자 없이 실행되므로 **analyze 모드가 자동 실행**된다.

```
daily-check-agent.exe 더블클릭
→ llama-server.exe 자동 기동 (llama.cpp 모드인 경우)
→ 메트릭 로딩
→ AI 분석 결과 출력
→ reports\ 에 MD 파일 저장
→ 종료 시 llama-server 자동 종료
```

## 폐쇄망 전달 패키지 구성

### llama.cpp 모드 (권장)

```
전달 파일
└── daily-check-agent.zip   ← build.bat 산출물 (모든 것 포함)
```

`runtime\llama-server.exe` 와 `runtime\models\*.gguf` 가 zip 안에 포함된다.
압축 해제 후 `daily-check-agent.exe` 더블클릭만 하면 된다.

### Ollama 모드

```
전달 파일
├── daily-check-agent.zip     ← PyInstaller 빌드 산출물
├── OllamaSetup.exe           ← https://ollama.com/download 에서 다운로드
└── (Ollama 설치 후 qwen3 모델은 ollama pull qwen3 으로 별도 설치)
```

## 주의사항

| 항목 | 내용 |
|------|------|
| 플랫폼 분리 | macOS 빌드 ≠ Windows 빌드, 반드시 각 OS 에서 빌드 |
| .exe 형식 | Windows 전용. macOS 빌드 결과물은 .exe 가 아님 |
| `_internal\` | Python 런타임 폴더, 이동하거나 수정하면 실행 불가 |
| 실행 위치 | `dist\daily-check-agent\` 폴더 안에서 실행 (config.yaml 이 있는 폴더) |
| `config.yaml` | Grafana URL / 토큰, llama_cpp.enabled 등 배포 전 반드시 편집 |
| AV 오탐 | PyInstaller .exe 를 일부 백신이 오탐 가능, UPX 비활성화로 완화 적용됨 |
| Python 버전 | Python 3.10~3.12 권장. 3.13 은 일부 라이브러리 호환 문제 가능 |

## 트러블슈팅

### `ModuleNotFoundError: No module named 'yaml'`
```bat
REM spec 파일 hiddenimports 확인
findstr yaml daily_check_agent.spec
```

### `FileNotFoundError: config.yaml`
```bat
REM 실행 위치 확인 — config.yaml 이 있는 폴더에서 실행해야 함
dir config.yaml
```

### `FileNotFoundError: llama-server.exe`
```
runtime\llama-server.exe 가 없음
→ llama.cpp 릴리스에서 Windows x64 zip 다운로드 후 복사
```

### `FileNotFoundError: *.gguf`
```
runtime\models\ 폴더에 GGUF 파일 없음
→ HuggingFace 에서 qwen3-0.6b-q4_k_m.gguf 다운로드 후 복사
```

### llama-server 포트 충돌 (8080 사용 중)
```yaml
# config.yaml 에서 포트 변경
llama_cpp:
  port: 18080
```

### 저사양 PC 응답 느림
```yaml
# config.yaml 튜닝
llama_cpp:
  context_size: 1024   # 2048 → 1024
  threads: 2           # 4 → 2
  max_tokens: 256      # 512 → 256
```
