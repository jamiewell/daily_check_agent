# 일일점검 에이전트 실행 가이드

## 1. 사전 준비 (최초 1회)

```bash
cd daily-check-agent

# 가상환경 생성
python3 -m venv .venv

# 가상환경 활성화
source .venv/bin/activate   # macOS / Linux
.venv\Scripts\activate      # Windows

# 패키지 설치
pip install -r requirements.txt
```

## 2. 매번 실행 전

```bash
cd daily-check-agent
source .venv/bin/activate
```

---

## 3. 명령어 모드

### `check` — 빠른 상태 확인 (LLM 없음)

```bash
python3 main.py check
```

- 메트릭 요약 테이블 출력
- 전일 대비 증감 비교 표 출력
- LLM 없이 동작 (가장 빠름)
- 리포트 파일 저장 안 함 (기본값)

```bash
# 리포트 파일도 저장할 때
python3 main.py check --save
```

---

### `analyze` — AI 분석 포함

```bash
python3 main.py analyze
```

- `check` 결과 + AI 종합 분석 텍스트 추가 출력
- 전체 상태 평가 / 이상 항목 / 전일 추세 / 조치 권고 자동 작성
- 리포트 파일 저장 안 함 (기본값)

```bash
# 리포트 파일도 저장할 때
python3 main.py analyze --save
```

---

### `predict` — 사용률 예측

```bash
python3 main.py predict
```

- 전일 24h 시계열 데이터를 분석해 향후 1h / 3h / 6h 사용률 예측
- CPU / 메모리 / 네트워크 / 디스크 각 파트별 slope 분석 (우상향 / 우하향 / 횡보)
- 임계치 도달 예상 시간 계산
- 종합 리스크 요약 테이블 + AI 자연어 해석 출력

```bash
# 특정 메트릭만 예측
python3 main.py predict --metric cpu
python3 main.py predict --metric memory
python3 main.py predict --metric network
python3 main.py predict --metric disk

# 예측 구간 변경 (기본: 1h, 3h, 6h)
python3 main.py predict --horizon 1,6,12

# AI 해석 없이 수치 테이블만
python3 main.py predict --no-llm
```

### `chat` — 대화형 질의응답

```bash
python3 main.py chat
```

터미널에서 자유롭게 AI와 대화하며 모든 기능을 사용할 수 있습니다.  
시작 후 `?` 또는 `도움말`을 입력하면 전체 명령어 목록이 표시됩니다.

#### chat에서 사용 가능한 전체 명령어

| 입력 예시 | 동작 |
|---|---|
| `현황 확인` / `현황 보여줘` / `빠른 점검` | 메트릭 테이블 + 전일 비교 **즉시 출력** (LLM 없음, 빠름) |
| `일일점검` / `점검` / `분석해줘` | 메트릭 + 전일 비교 + **AI 종합 분석** |
| `예측해줘` / `사용률 예측` / `트렌드` | 시계열 예측 1h/3h/6h + **AI 해석** |
| `리포트 만들어줘` / `리포트 생성` | 마지막 점검 결과를 **MD 파일로 저장** |
| `도움말` / `help` / `?` | 명령어 목록 표시 |
| `exit` / `quit` / `종료` | 에이전트 종료 |

> 위 키워드가 포함되지 않은 자유로운 문장은 **AI 일반 대화**로 처리됩니다.

#### 사용 예시 흐름

```
You > ?                          ← 명령어 목록 확인
You > 현황 확인                  ← 메트릭 테이블만 빠르게 확인 (LLM 없음)
You > 분석해줘                   ← AI 점검 분석 실행
You > prautap1 CPU가 높은 이유?  ← 분석 결과 기반 후속 질문 (일반 대화)
You > 예측해줘                   ← 사용률 시계열 예측
You > 앞으로 6시간 메모리 괜찮아? ← 예측 결과 기반 후속 질문
You > 리포트 만들어줘             ← 마지막 점검 결과를 파일로 저장
You > exit                       ← 종료
```

#### 토큰 관리

대화가 길어지면 LLM 컨텍스트(4096 토큰)가 소진됩니다.  
프롬프트에 현재 사용량이 표시되며, 90% 도달 시 초기화 여부를 묻습니다.

```
You [3710/4096tok] > ...

⚠  토큰 정리 필요  3710/4096tok (91%)
대화 이력을 초기화하시겠습니까? (y/n) > y
대화 이력 초기화 완료.

You > ...   ← 시스템 메시지만 남기고 새 대화 시작
```

## 4. 전역 옵션

모든 명령어 앞에 붙일 수 있습니다.

```bash
# 설정 파일 직접 지정
python3 main.py --config path/to/config.yaml check

# HTTP 통신 / 에러 상세 로그 출력
python3 main.py --debug analyze
```

## 5. 전형적인 사용 흐름

```bash
# 1) 빠른 상태 확인 (LLM 없음)
python3 main.py check

# 2) AI 분석까지 포함한 전체 점검
python3 main.py analyze

# 3) 사용률 예측
python3 main.py predict

# 4) 위 모든 기능을 대화로 사용
python3 main.py chat
```
