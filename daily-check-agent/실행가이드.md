# 일일점검 에이전트 실행 가이드

## 1. 사전 준비 (최초 1회)

```bash
cd daily-check-agent

# 가상환경 생성
python3 -m venv .venv

# 가상환경 활성화
source .venv/bin/activate

# 패키지 설치
pip install -r requirements.txt
```

## 2. 매번 실행 전

```bash
cd daily-check-agent
source .venv/bin/activate
```

---

## 3. 명령어 모드

### `check` — 빠른 상태 확인 (LLM 없음)

```bash
python3 main.py check
```

- 메트릭 요약 테이블 출력
- 전일 대비 증감 비교 표 출력
- `reports/` 폴더에 MD 리포트 자동 저장
- Ollama 없이 동작 (가장 빠름)

```bash
# 리포트 파일 저장 안 할 때
python3 main.py check --no-save
```

---

### `analyze` — AI 분석 포함 (Ollama 필요)

```bash
python3 main.py analyze
```

- `check` 결과 + Qwen3 AI 분석 텍스트 추가 출력
- 전체 상태 평가 / 이상 항목 / 전일 추세 / 조치 권고까지 자동 작성
- `reports/` 폴더에 MD 리포트 자동 저장

```bash
# 리포트 파일 저장 안 할 때
python3 main.py analyze --no-save
```

---

### `chat` — 대화형 질의응답 (Ollama 필요)

```bash
python3 main.py chat
```

- 터미널에서 자유롭게 AI와 대화
- 점검 키워드 입력 시 자동으로 메트릭 수집 후 분석 실행

**점검 트리거 키워드 (아래 중 하나 입력)**

| 입력 | 동작 |
|------|------|
| `일일점검` | 메트릭 수집 → AI 분석 → 리포트 저장 |
| `점검` | 동일 |
| `서버 점검` | 동일 |
| `점검 시작` | 동일 |
| `분석 시작` | 동일 |

**점검 이후 이어서 질문 가능한 예시**

```
You > 일일점검
(에이전트가 메트릭 수집 후 AI 분석 출력)

You > prautap1 CPU가 높은 이유가 뭔가요?
You > 조치 우선순위를 알려줘
You > 어제보다 메모리가 많이 증가했나요?
You > 네트워크 트래픽이 정상 범위인가요?
```

**종료**

```
You > exit
```

---

### `status` — Ollama 연결 상태 확인

```bash
python3 main.py status
```

- Ollama 서버 연결 여부 및 설치된 모델 목록 출력
- `analyze` / `chat` 실행 전 먼저 확인 권장

---

### `debug` — 환경 전체 진단

```bash
python3 main.py debug
```

- 패키지 설치 상태, 샘플 데이터 파일, Ollama 연결, LLM 응답까지 일괄 점검
- 에러 발생 시 원인 파악용

---

## 4. 전역 옵션

모든 명령어 앞에 붙일 수 있습니다.

```bash
# 설정 파일 직접 지정
python3 main.py --config path/to/config.yaml check

# HTTP 통신 / 에러 상세 로그 출력
python3 main.py --debug analyze
```

---

## 5. 전형적인 사용 흐름

```bash
# 1) Ollama 상태 확인
python3 main.py status

# 2) 빠른 상태 확인 (LLM 없음)
python3 main.py check

# 3) AI 분석까지 포함한 전체 점검
python3 main.py analyze

# 4) 결과를 보고 추가 질문이 있으면 대화 모드
python3 main.py chat
```

---

## 6. 출력 결과물

| 항목 | 위치 |
|------|------|
| 터미널 요약 테이블 | 실행 즉시 출력 |
| AI 분석 텍스트 | 터미널 출력 (`analyze` / `chat` 모드) |
| MD 리포트 파일 | `reports/YYYY-MM-DD_HH-MM-SS.md` |
